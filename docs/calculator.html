How to use it

Search for an element by its ISU code and select it. Its base value and the points for your chosen GOE come from the ISU scale. For a clean jump combination or sequence, join two or three jump codes with +, for example 3Lz+3T. Euler can be included between jumps, as in 3F+Eu+3S.

Bonuses, repeated-jump reductions and special calls within combinations are not calculated. Enter a listed individual element with its technical-call code when applicable. The calculator does not check whether an element or combination is permitted in your program.

The estimate appears after you select an element, with GOE initially set to 0. Enter the three already-averaged component marks and the applicable factor to include PCS. Enter the number of falls and the deduction per fall; the default is 1 point per fall. This fixed-rate estimate does not automatically apply other deductions or changing fall penalties. Your inputs are not saved when you leave this page.

Judges assess composition, presentation and skating skills against the component criteria. In an actual competition, the panel's marks are averaged under ISU rules and multiplied by the applicable factor; a selected GOE here represents one hypothetical grade, not the panel's result.
